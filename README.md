# Worst HLM Editor
**Worst HLM Editor** is an enhanced level editor for *Hotline Miami 2: Wrong Number*. It uses the game's identical file structure (`.hlm`, `.obj`, `.tls`, `.wll`, `.play`) for level creation, and leverages the contents of `.wad` and `.patchwad` files to interact directly with the game data.
## Installation
To install, download latest version archive from [Release](https://github.com/BabuinRiga/Worst-HLM-Editor/releases) and extract the archive into a dedicated folder of your choice.
## Features
- Load and save levels directly from the original game.
- Place and edit all types of items and their parameters.
- Unrestricted selection of objects, sprites, and tiles.
- Dynamic sprite loading from the base game and installed mods, including those bundled within custom levels and campaigns.
